# 7-Zip for macOS (SevenZipMac) — Product & UX Specification

## 1. Назначение продукта
Нативный файловый менеджер-архиватор для macOS на базе официального движка **7-Zip 26.06** (встроенного в процесс через динамическую библиотеку `libsevenzip.dylib`), объединяющий **функциональную логику классического 7-Zip File Manager (`7zFM`)** с **современным нативным интерфейсом уровня macOS Pro (ForkLift / Transmit)**.

Решает главную проблему существующих архиваторов на Mac (The Unarchiver, Archive Utility, Keka): вместо принудительной слепой распаковки архива целиком даёт полноценную навигацию внутри архивов любого размера, выборочное извлечение, предпросмотр, редактирование файлов на лету и гибкое создание архивов без рекламы и навязанных ограничений.

## 2. Подтверждённая UX-модель

### Визуальный язык (macOS Pro — Operate Mode)
- Системная пластика macOS (светлая и тёмная темы, нативные материалы боковой панели, иконки SF Symbols единого веса, системный шрифт SF Pro с табличными цифрами `monospacedDigit` для размеров, степеней сжатия, CRC и дат).
- Высокая информационная плотность без «воздушных» маркетинговых отступов: высота строки таблицы `24pt`, мгновенная сортировка по колонкам (`Имя`, `Размер`, `Сжатый размер`, `Изменён`, `Атрибуты`, `CRC`, `Метод`), чёткое разделение панелей `1px` и явный акцент активной панели в двухпанельном режиме.
- Компактный сайдбар быстрого доступа (Домашняя папка, Рабочий стол, Загрузки, Документы, Приложения, подключённые тома, недавние архивы) с возможностью скрытия.

### Бесшовная навигация «диск ↔ архив ↔ вложенный архив»
- Любая файловая панель работает с единым адресным пространством: обычные папки macOS и архивы открываются в одной и той же таблице без переключения в «другой режим программы».
- `Enter` / `Cmd+↓` / двойной клик по папке или любому поддерживаемому архиву входит внутрь него; внутри архива точно так же открываются подпапки и вложенные архивы (`tar.gz`, `.zip` внутри `.7z` и т.д.).
- Строка `..` вверху списка, `Backspace` или `Cmd+↑` поднимает на уровень выше — из подпапки в корень архива, а из корня архива обратно в папку на диске, где лежит архив.
- Над каждой панелью расположена кликабельная строка пути (хлебные крошки с индикатором границы архива), снизу — строка состояния (число папок/файлов, общий и выделенный объём).

### Однопанельный и двухпанельный режимы (`1 / 2 панели`)
- **Старт по умолчанию — 1 панель**: при открытии архива двойным кликом из Finder открывается чистое однопанельное окно прямо в корне этого архива (подъем вверх по `..` ведёт в родительскую папку Finder).
- **Переключение во 2-ю панель по `F9` (или кнопке тулбара)**: мгновенно открывает соседнюю панель (`Tab` переключает фокус между левой и правой панелями).
- **Операции между панелями в духе `7zFM`**:
  - `F5 Копировать` из панели с архивом в панель с папкой на диске → выборочно распаковывает выделенные элементы (с корректным срезом текущего префикса подпапки архива) прямо в открытую соседнюю папку.
  - `F5 Копировать` из панели с папкой на диске в панель с открытым перезаписываемым архивом (`7z`, `zip`, `tar`, `wim`) → упаковывает выбранные файлы прямо в текущую открытую подпапку этого архива.
  - `F5` / `F6` между двумя обычными папками на диске → копирует или перемещает файлы.
  - Drag-and-drop из окна архива напрямую в Finder (`NSFilePromiseProvider` — ленивая распаковка в точку сброса без предварительного копирования всего архива) и из Finder в окно.

### Работа с файлами внутри архива
- **`Пробел` (Quick Look)**: мгновенный системный предпросмотр `QLPreviewPanel` выбранного файла внутри архива.
- **Двойной клик / `Enter` по файлу внутри архива**: распаковка этого одного файла в изолированную временную сессию и открытие в системном приложении по умолчанию. Если архив поддерживает запись (`7z`, `zip`, `tar`, `wim`) и пользователь сохранил изменения во внешнем редакторе, файловый наблюдатель фиксирует изменение и предлагает обновить файл внутри архива (как в оригинальном `7zFM`).

### Верхний тулбар операций `7zFM`
- **Добавить (`+`)** — диалог создания/добавления в архив с полными настройками 7-Zip: формат (`7z`, `zip`, `tar`, `wim`), метод (`LZMA2`, `LZMA`, `PPMd`, `BZip2`, `Deflate`, `Copy`), уровень сжатия (Без сжатия … Ультра), размер словаря, солидный блок, разбиение на тома, пароль с AES-256 и шифрованием имён файлов (`-mhe=on` для `7z`).
- **Извлечь** — диалог извлечения с выбором папки назначения, режима путей и перезаписи.
- **Тест** — проверка целостности архива и зашифрованных данных (`CRC` / потоковая тестовая распаковка без записи на диск).
- **Копировать (`F5`) / Переместить (`F6`) / Новая папка (`F7`) / Удалить (`Del` / `Cmd+Backspace`) / Переименовать (`F2`) / Свойства (`Cmd+I`)**.
- **Переключатель `1 / 2 панели` (`F9`)** и поле быстрого фильтра/поиска (`Cmd+F`).

## 3. Технические и лицензионные границы
- **Движок**: официальный `7-Zip 26.06` (`ip7z/7zip`), скомпилированный в динамическую библиотеку `@rpath/libsevenzip.dylib` с ARM64 ASM-оптимизациями. Пароли передаются строго внутри процесса через C-колбэки (никогда не попадают в аргументы CLI или `ps`).
- **Форматы**: чтение и распаковка 70+ форматов 7-Zip (`7z`, `zip`, `rar`/`rar5`, `tar`, `gz`, `bz2`, `xz`, `zstd`, `dmg`, `iso`, `apfs`, `hfs`, `cab`, `wim`, `squashfs`, `rpm`, `deb`/`ar`, `cpio`, `chm`, `nsis`, многотомные `.001` и др.); создание и модификация — `7z`, `zip`, `tar`, `wim`, `xz`, `gz`, `bz2`. Формат RAR поддерживается только на чтение/извлечение согласно ограничениям лицензии unRAR.
- **Дистрибуция**: открытый исходный код, поставка через GitHub Releases (`.dmg` / `.app`) и Homebrew Cask без обязательной платной подписи Apple Developer ID; полная атрибуция LGPL-2.1, BSD-3-Clause, BSD-2-Clause и unRAR в `THIRD_PARTY_LICENSES.md` и окне «О программе».
