# Организация приложения

`Sources/Arkvello/AppViewModel.swift` — общее наблюдаемое состояние, создание панелей и связывание компонентов. Команды разделены на расширения в том же модуле:

| Файл `AppViewModel+…` | Ответственность |
| --- | --- |
| `Navigation` | Навигация, события панелей, восстановление и сохранение сеанса |
| `Finder` | Службы Finder, последовательное пакетное извлечение и повтор с паролем |
| `Archives` | Диалоги и выполнение создания/извлечения архивов |
| `Transfers` | Копирование, перемещение, добавление файлов и входящий drop |
| `FileActions` | Переименование, папки, удаление и свойства |
| `Clipboard` | Системный буфер обмена |
| `Inspection` | Контрольные суммы и проверка целостности |
| `Preview` | Активация файла, Quick Look и внешнее редактирование |
| `Operations` | Допуск операций, прогресс, отмена и ответы о перезаписи |

Модели запросов диалогов находятся в `AppRequests.swift`. Расширения используют общее состояние на `MainActor`; интерфейс не обращается напрямую к блокирующему движку.

`OperationCoordinator` допускает одну операцию до фактического завершения рабочего потока, включая отмену. `PasswordPromptQueue` сериализует запросы и доставляет ответ после закрытия sheet. `OperationReply` пробуждает ожидающий поток при ответе или отмене. `OperationResultBox` передаёт результат единственного рабочего потока в обработчик его завершения.

`PaneContentLoader` выполняет чтение и построение дерева через `PaneLoadWorker`. Поколения загрузки в `PaneViewModel` отбрасывают устаревшие результаты. `PanePresentation` готовит сортировку, индексы выбора и статистику вне главного потока.

Владение временными данными явно продлевается через `PaneArchiveContent` и `PaneTemporaryDirectory`. `ArchivePromiseContext` удерживает источник до исполнения обещания Finder и публикует готовый результат через `StagedReplacement`. `ExternalEditSessionStore` удерживает исходный архив и пароль независимо от навигации панелей. Сохранение `TempEditSession` сжимает отдельную копию файла; новая правка во время сжатия остаётся несохранённой.

Вложенные архивы доступны только для чтения и извлечения. Автоматического обновления цепочки внешних архивов нет; перед изменением вложенный архив требуется извлечь на диск.

`Extensions/ArkvelloQuickLook/ArchiveListing.swift` — общий рендер метаданных для расширения и тестовой цели `ArchivePreview`. Сам `PreviewProvider` отвечает только за API Quick Look. Рендер не извлекает содержимое и не обращается к паролям приложения или Keychain.
