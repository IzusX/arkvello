# Проверка этапов 5–6

Дата: 15 ноября 2026. Проверяемый бандл: `dist/Arkvello.app`, версия 0.1.0, сборка 4. Среда: Apple Silicon, macOS 27.0.1 (26A434), Swift 6.4.2. Проверка выполнена на рабочем дереве с незакоммиченными изменениями; это локальная сборка, не опубликованный релиз.

## Автоматические проверки

`swift test`: 54 проверки — 29 приложения, 21 ядра и 4 рендера Quick Look.

- Загрузка папок, архивов и вложений; отмена, смена вкладок, устаревшие результаты и время жизни временных каталогов.
- Поиск с задержкой, сортировка больших списков, выбор строк и ограничения рекурсивной выдачи.
- Единственная активная операция, объединение прогресса, отмена ожидания ответа и закрытие диалогов перед повтором.
- Реальное пакетное извлечение Finder: неверный пароль, повтор только оставшихся архивов, отмена запроса без создания выходных файлов.
- Внешнее редактирование: пароль исходного архива после навигации, повтор после неверного пароля, сохранение шифрования заголовков и новая правка во время сжатия.
- Исполнение обещания Finder после освобождения снимка панели; сохранность существующего назначения при ошибке.
- Запрет изменения вложенного архива без изменения внешнего файла.
- Рендер Quick Look: экранирование имён, отсутствие содержимого файлов в HTML, зашифрованные заголовки, повреждённые и слишком большие архивы.

## Проверка через интерфейс

На итоговой сборке подтверждены:

- Открытие ZIP с папкой и вложенным ZIP, вход во вложение и возврат назад.
- Отметка «ЧТЕНИЕ» и пояснение ограничения вложенного архива.
- Quick Look текстового файла из вложенного ZIP внутри приложения.
- Открытие файла из внешнего ZIP в TextEdit, сохранение, обнаружение изменений, команда «Обновить в архиве». Содержимое ZIP дополнительно прочитано независимо и совпало с сохранённым текстом.
- Служба Finder `Extract to Subfolder`: создание папки и правильное содержимое извлечённого файла.
- Повторный вызов службы с конфликтом, появление сравнения файлов и отмена без зависшего прогресса.

Временные диагностические копии приложения из прошлой проверки удалены. Установленные пользователем `7-Zip.app` и `Arkvello.app` не заменялись, ассоциации файлов не менялись.

## Границы проверки перед релизом

| Проверка | Статус |
| --- | --- |
| Срезы arm64 и x86_64 приложения, библиотеки и расширения | Включены в Universal-сборку; проверяются скриптом сборки |
| Подпись бандла | Локальная ad-hoc, проверяется `codesign --verify --deep --strict` |
| Запуск на физическом Intel Mac | Не проверен; Rosetta на этом Mac отсутствует |
| Минимальная поддерживаемая macOS 14 | Цель сборки 14.0; запуск на macOS 14 отдельно не проверен |
| Расширение Quick Look именно сборки 4 в Finder | Не подтверждено: система использует ранее установленное расширение `io.github.izusx.sevenzipmac.quicklook` из `/Applications/7-Zip.app`; новый рендер покрыт тестами и расширение собрано |
| Перетаскивание реальным жестом между приложением и Finder | Исполнение обещания покрыто интеграционным тестом; сам жест в этой проверке не воспроизводился |
| Холодный запуск приложения только через службу Finder | Проверялся вызов службы при запущенном приложении; отдельный холодный запуск нужно повторить |
| Gatekeeper скачанного DMG и Homebrew | Нового скачанного релиза и опубликованного tap нет; не проверены |

Для завершения проверки дистрибуции установите именно сборку 4 в выбранное место, проверьте её расширение Quick Look в настройках macOS и повторите просмотр обычного и зашифрованного архива. Затем закройте приложение и вызовите каждую службу из Finder; проверьте компактное окно операции, пароль, конфликт, отмену и закрытие после успеха. На Intel и macOS 14 повторите запуск, создание/извлечение, просмотр и перетаскивание. Наличие x86_64-среза не считается проверкой запуска на Intel.

При очистке проекта устаревшие DMG, source.tar.gz, Cask и SHA256SUMS удалены. В `dist` оставлен актуальный `Arkvello.app` сборки 4. Для публичного релиза полный комплект артефактов нужно пересоздать из точной проверенной и закоммиченной ревизии согласно `DISTRIBUTION.md`. Временные тестовые файлы, журналы проверок и кэши сборки также удалены; результаты проверок приведены в этом отчёте.

## Проверки при публикации на GitHub

После локального сеанса проект загружен в `IzusX/arkvello`, а отдельный tap — в `IzusX/homebrew-tap`. [CI ревизии 7ba3503](https://github.com/IzusX/arkvello/actions/runs/43705109443) успешно выполнил все 54 теста, сборку приложения и Quick Look, проверку подписи и неизменности исходников отдельно на Apple Silicon и Intel с macOS 15 / Xcode 16.4. Это автоматическая проверка на Intel, а не проверка окон, Finder и перетаскивания вручную; ограничения локального сеанса выше сохраняются.

Для совместимости с Xcode 16.4 файл точки входа с `@main` переименован в `ArkvelloApp.swift`. Тесты навигации используют явные типы URL и синтетические пути вместо существующей только на Mac разработчика папки Downloads.

Workflow проверены через `actionlint`. Генерируемый cask проверен через `brew style`. Проверка обновляющего скрипта tap подтвердила приём корректного комплекта, отказ при изменённом DMG и сохранение предыдущего cask при ошибке. Публичные релизы собираются заново из тега; актуальные результаты выпуска и аудита cask доступны во вкладках Actions обоих репозиториев.
